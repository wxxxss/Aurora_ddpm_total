# First revision archive

This directory contains all scripts previously located directly under `paper_modif/`. The move preserves their content and Git object hashes. Some archived scripts still contain the original `paper_modif/R...` absolute/relative paths and `SCRIPT_PATH.parents[2]` assumptions; these must be adjusted before rerunning after the directory move (the scripts are preserved as a historical record). New experiments should be created under `paper_modif/Second_revision/` instead of changing first-round artifacts.
